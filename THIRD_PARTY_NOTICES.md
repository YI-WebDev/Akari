## OpenPGP.js (LGPL-3.0-or-later)

`extension/src/third_party/openpgp.js` is the unmodified `dist/openpgp.min.mjs` of the npm package `openpgp` 6.3.2. The only change is that the trailing source-map comment is removed and two header lines are added. Its Argon2 support uses a WebAssembly module that is embedded inside the same file; no separate `.wasm` file ships. The LGPL-3.0 text is in `extension/src/third_party/openpgp.LICENSE`; the GPL-3.0 text it incorporates by reference is in `extension/src/third_party/GPL-3.0.txt` (the official text from https://www.gnu.org/licenses/gpl-3.0.txt).

Rebuild or replace the bundled copy:

1. Install the dependencies: `npm ci` (this installs `openpgp@6.3.2`, pinned in `package-lock.json`).
2. Run `node scripts/build-openpgp.mjs`. It copies `node_modules/openpgp/dist/openpgp.min.mjs` to `extension/src/third_party/openpgp.js` and `node_modules/openpgp/LICENSE` to `extension/src/third_party/openpgp.LICENSE`.
3. To use a modified or different version, change the `openpgp` version in `package.json` (or point `node_modules/openpgp` at your own build of https://github.com/openpgpjs/openpgpjs, whose `npm run build` produces `dist/openpgp.min.mjs`) and run step 2 again, or replace `extension/src/third_party/openpgp.js` directly. The extension imports it as an ES module, and it has no build step of its own: reload the unpacked extension afterwards.

The build script refuses a bundle that uses `eval` or `new Function`, because the extension's Content Security Policy forbids them.

## jsQR (Apache-2.0)

`extension/src/third_party/jsqr.js` is `dist/jsQR.js` of the npm package `jsqr` 1.4.0 wrapped as an ES module by `scripts/build-jsqr.mjs`. The license text is `extension/src/third_party/jsQR.LICENSE`.

## Fonts (SIL Open Font License 1.1)

The `.woff2` files and `fonts.css` under `extension/src/assets/fonts/` are generated by `tools/build-fonts.mjs` from the npm packages `@fontsource/jetbrains-mono` 5.3.0 and `@fontsource/m-plus-1-code` 5.3.1 (subsets are unmodified copies of the packaged files). Each family's license, including its copyright line, is in `LICENSE-<package>.txt` in the same folder. The fonts are not sold on their own.

## Public Suffix List (MPL-2.0)

`extension/src/shared/psl-data.js` is generated by `scripts/build-psl.mjs` from `public_suffix_list.dat` (version `2026-10-31_14-17-28_UTC`, as recorded in the file header). The rules are converted to ASCII and stored as one string. The Public Suffix List is available under the Mozilla Public License 2.0; upstream is https://publicsuffix.org/. The full MPL-2.0 text is in `extension/src/shared/PSL-MPL-2.0.txt` (the official text from https://www.mozilla.org/media/MPL/2.0/index.txt). To regenerate: obtain `public_suffix_list.dat` from upstream and run `node scripts/build-psl.mjs <path-to-public_suffix_list.dat>`.
